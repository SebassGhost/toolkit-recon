
# Subdomain Enum

Modulo de enumeracion de subdominios por fuentes activas y pasivas.

## Tecnicas

- Fuerza bruta con wordlist.
- Fuentes pasivas OSINT.
- Filtrado de resultados por deteccion de wildcard DNS.

## Salida

Incluye `results` y `metrics` (intentos DNS, resueltos, filtrados por wildcard, duracion).
