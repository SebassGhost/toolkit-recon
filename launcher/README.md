
# Launcher

Esta carpeta incluye scripts para ejecutar Toolkit-Recon en distintos sistemas operativos.

## Archivos

- `run.ps1`: ejecucion en PowerShell.
- `run.bat`: ejecucion en CMD/Windows.
- `run.sh`: ejecucion en Bash/Linux/macOS.

## Uso

Ejecuta el script correspondiente desde la raiz del proyecto para iniciar el toolkit.
